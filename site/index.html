第一次使用

安裝程式會告訴你缺少什麼

三個步驟，全程都會先問過你才動作。

1

下載並解壓縮

所有檔案都放在同一個資料夾，不會擅自寫入系統目錄，也不需要系統管理員權限。

macOS・Linux・WSL 也可以直接在終端解壓：

tar -xzf komica-terminal-reader-posix.tar.gz

Windows 對著 ZIP 按右鍵「解壓縮全部」即可。

2

執行開始檔

Windows 雙擊 Windows_開始使用.cmd；macOS 雙擊 macOS_雙擊開始.command；Linux／WSL 執行 sh ./Linux_WSL_開始.sh。

3

開啟閱讀器

第一次依畫面提示安裝；以後使用同一個開始檔即可直接啟動。程式本體收在 app 資料夾。

第一次啟動需要連網

安裝器會用固定版本從套件庫取得三個相依套件，實測約需下載 85 MB， 全部裝在解壓縮資料夾內的獨立環境裡。畫面會先列出清單並等你輸入 y，拒絕也完全可以繼續使用。之後啟動不再需要網路連線， 除了讀取討論串本身。

macOS 第一次會被 Gatekeeper 擋下

這是所有未經 Apple 簽章程式的共同待遇，不代表檔案有問題。 在 macOS_雙擊開始.command 上按右鍵 →「開啟」， 再按一次「開啟」即可；之後雙擊就正常了。

畫質

圖片好不好看，取決於你的終端

終端要支援像素圖形協定，貼文裡的圖才會是真正的圖片；不支援的終端只能 用字元拼出低解析度的近似畫面。閱讀器兩種情況都能用，差別只在畫質。

高畫質

支援像素圖形的終端

Kitty、Ghostty、WezTerm、 iTerm2、Windows Terminal、Konsole、 foot 等。圖片、GIF 與 WebM 都直接畫在討論串裡。

相容模式

其他終端

macOS 內建的終端機、舊版 Windows 主控台等。畫面仍然完整可讀， 但圖片會退回字元拼貼。macOS 上雙擊開始檔時，閱讀器會自動找看看 你有沒有裝上面那些終端，有就直接在那裡開；沒有也只會提示， 不會自行下載或安裝任何東西。
